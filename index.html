About

This tool calculates line-of-sight between two points by:

  • Sampling elevation data along the path
  • Adding antenna heights to terrain elevation
  • Drawing a straight line between elevated points
  • Accounting for Earth curvature (standard 4/3 Earth radius for atmospheric refraction)
  • Checking if terrain blocks this line

Fresnel zone: The calculation requires 60% of the first Fresnel zone to be clear (assumed 915 MHz frequency) to account for radio wave diffraction effects. The dotted line on the profile marks this boundary — terrain above it counts as an obstruction.

Elevation data: Terrain Tiles (Mapzen / AWS Open Data; sources include USGS 3DEP ~10 m in the US, SRTM and others worldwide), with Open-Meteo (Copernicus DEM, ~90 m) as a fallback. Bare-earth terrain only: trees and buildings are not included.
